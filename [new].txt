● MULTI-VIEWER SIDEBAR IMPLEMENTATION GUIDE

  Based on my analysis of the Potree sidebar system, here's a comprehensive guide for implementing working sidebars in each multi-viewer instance:

  1. SIDEBAR STRUCTURE ANALYSIS

  Four Main Dropdown Sections:
  - APPEARANCE (menu_appearance) - Rendering options, sliders, checkboxes
  - TOOLS (menu_tools) - Measurement tools, clipping tools, navigation
  - SCENE (menu_scene) - Objects tree, properties, export functions
  - Classification (menu_filters) - Point cloud filters, classification lists

  2. CRITICAL DEPENDENCIES

  Core Requirements:
  - jQuery UI (accordion, sliders)
  - Custom selectgroup plugin (lines 248-321 in Potree.js)
  - Resource path management (Potree.resourcePath for icons)
  - Event binding system for viewer interactions
  - Spectrum color picker for classification colors
  - JSTree for scene object hierarchy

  3. APPEARANCE SECTION - DETAILED BREAKDOWN

  Components:
  1. Point Budget Slider (#sldPointBudget) - Controls point rendering count
  2. Field of View Slider (#sldFOV) - Camera FOV control
  3. EDL Checkboxes & Sliders - Eye-Dome-Lighting controls:
    - #chkEDLEnabled - Enable/disable checkbox
    - #sldEDLRadius, #sldEDLStrength, #sldEDLOpacity - Parameter sliders
  4. Background Options (#background_options) - Selectgroup for skybox/gradient/etc
  5. Splat Quality (#splat_quality_options) - Standard/HQ selectgroup
  6. Other Controls - Min node size, bounding box, freeze checkboxes

  Key Implementation Pattern:
  // Slider initialization (lines 1281-1287)
  sldPointBudget.slider({
      value: this.viewer.getPointBudget(),
      min: 100 * 1000,
      max: 10 * 1000 * 1000,
      step: 1000,
      slide: (event, ui) => { this.viewer.setPointBudget(ui.value); }
  });

  // Event listener for updates (lines 1321-1324)  
  this.viewer.addEventListener('point_budget_changed', (event) => {
      $('#lblPointBudget')[0].innerHTML = Utils.addCommas(this.viewer.getPointBudget());
      sldPointBudget.slider({value: this.viewer.getPointBudget()});
  });

  4. MULTI-VIEWER IMPLEMENTATION STRATEGY

  Step-by-Step Process:

  Phase 1: Hamburger Icon & Container

  1. Create hamburger menu button for each viewer
  2. Position sidebar container relative to viewer bounds
  3. Implement toggle show/hide functionality

  Phase 2: HTML Template Loading

  1. Load sidebar.html via AJAX for each viewer
  2. Update all element IDs with viewer-specific suffixes
  3. Maintain element relationships and structure

  Phase 3: Element ID Scoping

  // Pattern for ID updates
  updateElementIdsForViewer(container, viewerId) {
      const elements = container.find('[id]');
      elements.each((index, element) => {
          const oldId = element.id;
          element.id = `${oldId}_${viewerId}`;

          // Update related selectors
          container.find(`[for="${oldId}"]`).attr('for', `${oldId}_${viewerId}`);
          container.find(`label[for="${oldId}"]`).attr('for', `${oldId}_${viewerId}`);
      });
  }

  Phase 4: Scoped jQuery Selectors

  - Replace global selectors like $('#sldPointBudget')
  - Use scoped selectors within viewer context: container.find('#sldPointBudget_viewerId')
  - Maintain selectgroup functionality with updated IDs

  Phase 5: Viewer Integration

  - Pass specific viewer instance to each sidebar
  - Bind events to correct viewer methods
  - Ensure resource paths work correctly

  5. SELECTGROUP PLUGIN CONSIDERATIONS

  Critical Behavior (lines 252-315):
  - Uses element ID as radio button group name
  - Creates fieldset with radio buttons
  - Applies jQuery UI styling classes
  - Requires unique IDs per viewer instance

  Multi-viewer Fix:
  // In selectgroup plugin, groupID becomes:
  let groupID = `${rootID}`; // Already uses unique viewerId suffix

  6. EVENT BINDING PATTERNS

  Two-way binding required:
  1. UI → Viewer: Slider changes update viewer state
  2. Viewer → UI: Viewer events update UI elements

  Example Pattern:
  // UI to Viewer
  sldFOV.slider({
      slide: (event, ui) => { this.viewer.setFOV(ui.value); }
  });

  // Viewer to UI  
  this.viewer.addEventListener('fov_changed', (event) => {
      $('#lblFOV')[0].innerHTML = parseInt(this.viewer.getFOV());
      $('#sldFOV').slider({value: this.viewer.getFOV()});
  });

  7. RESOURCE PATH MANAGEMENT

  Icons and Assets:
  - All toolbar icons use Potree.resourcePath + '/icons/...'
  - Ensure resourcePath is properly set before sidebar initialization
  - Critical for measurement tools, navigation icons, export buttons
